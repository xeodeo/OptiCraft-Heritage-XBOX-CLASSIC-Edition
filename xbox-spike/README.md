# xbox-spike

The working folder used while bringing the Xbox port up: build and test
scripts, gdb helpers, the controller autopilot, logs and screenshots from the
debugging sessions (xemu and the real console's network log `netlog.txt`).
Kept as a record; the maintained tools are in `scripts/xbox/tools` and the
port is documented in `docs/XBOX_PORT.md`. Paths inside the scripts point at
the original developer's machine.
